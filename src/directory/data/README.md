# Worldwide directory locations

Derived from cities.json 1.1.66 and the GeoNames Gazetteer, licensed under CC BY 4.0.

Sources: https://github.com/lutangar/cities.json and https://www.geonames.org/
License: https://creativecommons.org/licenses/by/4.0/ (also included in LICENSE.txt).

Coordinates and second-level administrative codes were removed, duplicate city names within each region were merged, and country names were resolved using English Intl.DisplayNames. This static file is loaded only when the location picker is first opened. Users can also select a manually entered location not listed in the dataset.
